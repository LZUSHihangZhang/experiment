## 目录约定

每个实验统一按以下结构组织：

```
<实验名>/
├── 报告/            # ✅ 最终提交的报告（PDF），文件名为《<实验名>.pdf》
├── 报告源码/        # 📝 LaTeX 源码（.tex）+ 报告所需的全部图片，可独立重新编译
│   └── 参考讲义/    #   该实验的指导书/仪器说明（.doc/.docx/.pdf），供回溯
└── 代码与数据/      # ⚙️ 数据处理脚本（.py）、原始数据（.xlsx/.txt）、拟合与结果图
    └── 原始数据/    #   仪器直接导出的原始数据（区别于处理后的中间文件）
```

> 图例：
> - ✅ `报告/` 里一定有最终 PDF（`铁磁共振`、`光电效应` 除外，见下表 ⚠️ 标注）
> - 📝 `报告源码/` 有 `.tex` 即说明该报告的排版源文件一并归档
> - ⚙️ `代码与数据/` 里是可复现实验数据的脚本与原始数据

LaTeX 编译产物（`.aux`、`.log`、`.synctex.gz` 等中间文件）统一由 `.gitignore` 排除，不进入版本库。

## 特别说明

1. **大型讲义 PDF 未纳入**：《近代物理实验（第二版）》(127 MB) 超出 GitHub 100 MB 单文件限制；《新版实验书含目录扫描质量差》(19 MB) 扫描质量差；《近代物理实验讲义补充》(2.9 MB) 与实验关系较弱。每实验的**指导书/讲义**已随附在 `报告源码/参考讲义/` 中。
2. **重复 `.zip` 未纳入**：原仓库与本地目录里的 `*.zip`（磁光克尔效应 / 巨磁电阻 / XRD / 热电子发射 / 阿贝成像图片 等）均为解压内容的打包备份，直接上传会造成冗余，因此只用其解压出的原始文件。
3. **去重合并**：GitHub `experiment` 原来的 15 篇报告 PDF 与本地同名 PDF 字节完全一致（同一文件），合并时只保留一份；`电光效应.pdf` 原是 2 字节的损坏空文件，已用本地完整版（4 页）替换。
4. **大文件提示**：`磁滞回线(2025-09旧版)`、`RLC暂态电路`、`核磁共振` 等报告因内嵌全彩屏摄/MRI 图像体积较大（7~20 MB），克隆时可用 `git clone --depth 1` 减小传输量。
5. **格式说明**：`pn结①/②`、`迈克尔逊干涉①/②` 为同一装置的两次独立实验（首测 / 复测）。

## 使用方法

### 阅读报告

直接点击 GitHub 网页上的 PDF 即可在线预览（仓库根导航 `近代物理实验/<实验名>/报告/`）。

### 重新编译 LaTeX 报告

报告使用 UTF-8 / CJK 编写，建议 XeLaTeX 编译（以黑体辐射为例）：

```bash
cd 近代物理实验/黑体辐射/报告源码
latexmk -xelatex document.tex      # 或：xelatex document.tex
```

> 依赖：TeX Live + ctex 宏包。求不折腾可跳过——`报告/` 里已有编译好的 PDF。

### 运行数据处理脚本

大部分脚本只需 Python 科学计算三件套：

```bash
pip install numpy matplotlib scipy pandas
python 近代物理实验/巨磁电阻/代码与数据/1.py
```

脚本中若引用了报告目录的相对路径图片，`cd` 到相应 `代码与数据/` 下执行即可。

### 增加新实验 / 纠错

欢迎直接提交：新建实验请沿用上面统一的三级目录；报告 PDF 放 `报告/`，对应 `.tex` 与图片放 `报告源码/`，脚本与数据放 `代码与数据/`。

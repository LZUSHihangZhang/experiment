# 大学物理实验 · 归档

作者：张世航 (Shawn Zhang) · 兰州大学物理学院

本科期间电磁学 / 光学 / 近代物理三门实验课的**完整归档**：最终报告（PDF）、LaTeX 源码、数据处理代码与原始数据。由原 `experiment` 与 `modern-physics-experiments` 两个仓库合并整理而成（2026-09）。

## 目录结构

```
experiment/
├── 电磁学实验/      # 7 个实验
├── 光学实验/        # 9 个实验
└── 近代物理实验/    # 16 个实验 + 期末复习资料
```

每个实验按统一结构组织：

```
<实验名>/
├── 报告/            # ✅ 最终提交报告（PDF）
├── 报告源码/        # LaTeX 源码（.tex）+ 所需图片，可独立编译
│   └── 参考讲义/    #   实验指导书 / 仪器说明（.doc/.docx/.pdf）
└── 代码与数据/      # 数据处理脚本（.py）、原始数据（.xlsx/.txt）、拟合与结果图
    └── 原始数据/    #   仪器导出的原始数据
```

## 说明

- **大型讲义 PDF 未纳入**：《近代物理实验（第二版）》(127MB)、《新版实验书含目录扫描质量差》(19MB)、《近代物理实验讲义补充》因超出 GitHub 单文件限制/质量原因未上传。每实验的指导书（参考讲义）已随附。
- **重复 .zip 未纳入**：原仓库与本地目录中的 `*.zip` 压缩包已用其解压出的原始文件替代。
- LaTeX 编译产物（`.aux`、`.log`、`.synctex.gz` 等）不纳入版本控制（见 `.gitignore`）。
- 报告中若引用了本地绝对路径的图片，在 `报告源码/` 下略作调整即可重新编译。
